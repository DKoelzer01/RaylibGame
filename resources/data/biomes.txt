# Biome variants (#1964, #1977; plan: https://claude.ai/artifact/5ajPzE3GJb5QVvXc5tneyQ).
# The biome types (Ocean, Jungle, ... Polar) are picked from the climate in code (PlanetField::biomeOf); a regional noise
# (~2.5 km patches) then picks a variant inside the type. One block per variant:
#   variant <type>.<id>      the type's lower-case name, a dot, the variant's id
#     name    <text>         shown to players (default: the id)
#     weight  <n>            its share of the type's area, relative to the type's other variants (default 1)
#     elev    <min> <max>    optional gates: m above sea level, C (annual mean) and moisture 0..1, "-" = open; where a
#     temp    <min> <max>    gate fails the point falls to the type's next variant. The first variant of a type is its
#     moist   <min> <max>    base (the biome as it was): it takes no gate, it is the fallback.
# Weights and gates are GUESSes for the first playtests (the user approved the set, 2026-11-27).
