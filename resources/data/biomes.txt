# Biome variants (#1964, #1977; plan: https://claude.ai/artifact/5ajPzE3GJb5QVvXc5tneyQ).
# The biome types (Ocean, Jungle, ... Polar) are picked from the climate in code (PlanetField::biomeOf); a regional noise
# (~2.5 km patches) then picks a variant inside the type. One block per variant:
#   variant <type>.<id>      the type's lower-case name, a dot, the variant's id
#     name    <text>         shown to players (default: the id)
#     weight  <n>            its share of the type's area, relative to the type's other variants (default 1)
#     elev    <min> <max>    optional gates: m above sea level, C (annual mean) and moisture 0..1, "-" = open; where a
#     temp    <min> <max>    gate fails the point falls to the type's next variant. The first variant of a type is its
#     moist   <min> <max>    base (the biome as it was): it takes no gate, it is the fallback.
#     flora   <trees> <bushes> <stones> <size>   (#1978) multipliers on the type's flora (trees.cpp FloraOf; "-" = 1)
#     cover   <0..1>         least tree odds anywhere in it (a closed canopy; default: the type's)
#     species <name> <w> ... tree species weights (names: woodspecies.h, looks: trees.txt); default: the type's broadleaf or
#                            conifer mix. Above the tree-line band a warm variant still grows conifers.
#     tint    <grass r g b> <leaf r g b>   (#2032) colour multipliers (linear) on grass (blades and ground) and on leaves
#                            (trees, bushes, the far canopy), over the climate colour, which keeps 40% of its pull. On a
#                            type's base it is the type's tint; another variant without one takes its base's; "- - -"
#                            keeps the base's for that group. Default 1. RAYLIBGAME_BIOME_TINT=0: off. Values: GUESS.
#     sizes   <bushes> <stones> <grass>   (#1995) size-class shifts on the type's own (trees.cpp/biomevariants.cpp:
#                            SmallFloraSizesOf): -1 mostly small .. +1 mostly large and extra large (thickets, boulders,
#                            waist-high grass); "-" = 0. Values: GUESS.
#     shrubs  <round> <mat> <upright>     (#1995) bush kind weights (default: the three alike)
#     rubber  <percent>      (#2012) the share of its felled trees that give one rubber (default 0; jungle trees always do)
# Variants cross-fade over ~200 m at their borders (the flora reads its variant ~100 m off per plant).
# Weights and gates are GUESSes for the first playtests (the user approved the set, 2026-11-27).
