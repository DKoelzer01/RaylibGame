# Research nodes (#1030; the factory and progression doc, section 7.6). Tiers 3-7 are researched in labs with packs.
# One node per line, fields separated by |:
#   node <id> | <name> | tier <3..7> | core | branch <line> | units <n> | time <seconds per unit> | packs <item> [<item>...]
#        | needs <node> [<node>...] | unlocks <kind>:<id> [...] | tome <page>
# - core nodes are required for their tier's milestone; branch nodes (combat, logistics, efficiency, magic, ...) are free.
# - a unit takes one of each listed pack and `time` seconds in one lab; N labs run N units at once.
# - a node's packs are its tier's kind and every earlier kind (decided); needs only name nodes of its tier or earlier.
# - unlocks: recipe:<output item> (a hand or machine recipe), machine:<part>. Nothing is gated by them yet: the gating
#   lands with the tier ladder rewrite and save migration (doc section 8, steps 8-10 and 14).
# - branch nodes give content (machines, recipes, methods), never percentages (decided 2026-11-20, second pass).
# - tome <page>: a magic cross link (#1001); no core node needs one.
# All counts and times are first guesses, to tune after playtests.
