# Mana kinds and their algebra (#1001, magic doc section 3; #1248 step 1, #1252 step 5).
# Four base kinds; every other kind is one step from them (no compound of compounds in v1):
#   combine <a> <b>  two different base kinds make a compound (A + B)
#   invert <a>       a kind turned to its opposite effect (~A): a base kind, or Life
#   cancel           A + ~A annihilate into this kind (Aether, the neutral hub); exactly one kind cancels
# One kind per line, fields separated by |:
#   kind <id> | <name> | latin <flavour> | base | combine <a> <b> | invert <a> | cancel | status <effect> | colour <RRGGBB> | slice 1
# - name: the plain English name in the game; latin: flavour shown in the tome only.
# - status: the combat status effect the kind applies (burn, chill, shock, bleed, poison, knockback, root; none if absent).
# - slice 1: in the first playable slice (decided 2026-11-21: the four bases, Aether, Frost, Storm, Shard, Rot).
#   The other kinds come with alchemy and wards.
# - At most 16 kinds in v1 (decided): no inverses beyond these.
# A kind and its inverse never share a jar or a pipe: they cancel.
