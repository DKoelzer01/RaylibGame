# Tree species (#1995 phase 2). The species list and each one's structure (its form) are code (src/engine/woodspecies.h,
# trees.cpp); this file sets how each looks and what it drops. One block per species:
#   species <name>          one of: oak birch maple pine spruce acacia kapok mangrove krummholz snag baobab tree_fern palm willow
#     log     <item>        what felling it drops (items.txt)
#     bark    <r g b>       multiplier on the shader's bark brown (linear; capped at 0.85 after it)
#     leaf    <r g b>       multiplier on the climate leaf colour, after the biome's tint (biomes.txt `tint`)
#     texture <name>        bark texture: furrows birch plates rings smooth
#     size    <n>           scale multiplier over the biome's (default 1)
# Missing keys keep the code's defaults (every tint 1, furrows, size 1, log oak_log). Biomes pick species with
# biomes.txt `species`. The phase-2 values (acacia on) are GUESSes for the playtest; the new species drop existing logs
# (their own log items can come later).
