# (#1871) Which runner scenarios a PR's changes need: its "affected" set (tools/ci/ci_plan.sh). Each line is
#   <extended regex on a changed path> | <what to run: comma-separated scenario names or tag:X; ALL = every runner
#                                         scenario; SERVER = the dedicated server and join tests>
# Every line that matches a changed path adds its targets. A changed scenario file (tests/scenarios/*.cpp) adds its own
# scenarios. A changed file under src/ or resources/ that no line matches adds the smoke set (DEFAULT below); a change
# only to docs or tools runs no scenario (the build and the unit tests still run). Only the runner's tags belong here
# (the two lists in .github/workflows/selfhosted.yml); local-only scenarios (perf, visual, ...) run on the PC.
# When in doubt, map wider: a missed regression surfaces only in the next batched run, hours later.
DEFAULT | tag:world

^src/space/scenario[a-z_]*\.(h|cpp)$ | ALL
^src/engine/(jobsystem|profiler|logger|utils/[a-z_]+)\.(h|cpp)$ | ALL
